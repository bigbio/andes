# Archive — first-half-2026 planning, spec and research documents

These 49 files were written between 2026-05 and 2026-08. They were moved here on
2026-09-04 from a second, unversioned documentation tree at the workspace root, so that
all documentation lives in one version-controlled place.

They are kept as a decision record, not as current guidance. **Most describe campaigns
that have since concluded, and several describe approaches that were subsequently
refuted by measurement** — for example the RS³ spectral-significance work
(`2026-06-29-rs3-*`), which was benchmark-refuted on all three gold datasets and
abandoned. Treat every number in here as historical: the authoritative, current results
live in `docs/benchmarks/` and in the project's memory notes.

Filenames flatten the original directory structure with `_` (for example
`internal-docs_specs_....md` was `internal-docs/specs/....md`).

# andes Hybrid Glyco Engine — Design

**Status:** approved (user, 2026-06-30) → autonomous experiment-gated build.
**Goal:** intact N-glycopeptide identification in andes that combines DB-constrained precision, Glyco-Decipher-style database-independent discovery, and andes-native learned scoring — beating MSFragger-Glyco on glyco peptide+protein IDs at matched FDR while finding glycans the DB-only tools miss.

## Why (the evidence)

- The de-novo-Y-ladder-alone backbone solver (Phase-1 prototype) caps at **60% overall / 38% sparse** searchable-backbone — structurally below a usable bar (the sparse stratum lacks Y-ladder; ranking fixes confirmed at the ~83% top_k=500 ceiling).
- **E0 make-or-break (2026-06-30):** on PXD025455 serum N-glyco truth, a ~1,600-composition N-glycan list explains **~85% of confident glyco deltas** (expect≤0.01). So a **DB branch** determines the backbone *exactly* (`precursor − glycan`) for the bulk, and de-novo is only the **novel-glycan fallback**. Projected hybrid searchable-backbone **~95%**. The ~15% out-of-list tail is precisely andes's differentiator vs DB-only engines.

## Architecture — four layers

**① Candidate generation (hybrid).** Per oxonium-gated spectrum:
- *DB branch (bulk):* for each composition `g` in the clean-room glycan list, backbone neutral = `precursor_neutral − g`; emit `(backbone, g)` candidates. Exact arithmetic.
- *De-novo branch (fallback):* the existing Y-ladder solver for spectra whose glycan is out-of-list (novel discovery).

**② Cross-spectrum backbone consensus (Glyco-Decipher).** Cluster spectra sharing a backbone (RT × backbone-mass × shared Y-anchors); pool evidence so sparse spectra borrow their backbone from glycan-sibling spectra. The DB-independent novel/sparse rescue.

**③ Learned scoring (andes signature).** A PRIDE-trained glyco fragment model predicts the expected backbone b/y + Y-ladder + oxonium pattern for a `(backbone, glycan)` pair; the match becomes **additive Percolator PIN features**. Disambiguates the chimeric (~40%) and deamidation (~20%) classes that mass-arithmetic ties.

**④ 2D FDR — in-house GBDT + 2D-TDC (NOT SVM, NOT Percolator on the glyco path).** Reuse `crates/model-train/src/gbdt` (pure-Rust trainer) + `crates/scoring/src/gbdt_eval.rs` (native evaluator) + `crates/search/src/tdc.rs` (q-values). Train a GBDT on the joint feature set (oxonium, Y-ladder, backbone score, glycan score, **+ decoy-class of each axis**) with **leakage-safe cross-validation**; walk q-values through TDC extended to the 2-D peptide×glycan target-decoy grid. **Gate: must clear 1% true entrapment-FDP** (it moves GBDT+TDC from its calibration/protein-gate role into production FDR).

## Clean-room provenance

The glycan composition list is generated by **combinatorial enumeration** over monosaccharide monoisotopic masses (HexNAc 203.07937, Hex 162.05282, Fuc 146.05791, NeuAc 291.09542, NeuGc 307.09033) with biologically-plausible N-glycan constraints — masses are physical facts, the enumeration is original. No vendor/competitor list is copied.

## Decomposition (each its own plan → build → gate)

| SP | Deliverable | Falsifiable gate |
|----|-------------|------------------|
| **A** | Hybrid candidate-gen + backbone (DB branch + de-novo fallback + clean-room list) | hybrid **searchable-backbone ≥ 90%** on PXD025455 (vs 60% de-novo-alone) |
| **B** | PRIDE-trained glyco fragment model → additive PIN features | features net-positive on glyco PSMs at 1% FDP |
| **C** | Cross-spectrum backbone consensus | recovers backbones the per-spectrum branch misses on the out-of-list tail |
| **D** | 2D in-house-GBDT FDR + comparative benchmark | **PR gate**: ≥ MSFragger-Glyco glyco peptide+protein IDs at matched FDR (PXD025455 + PXD055856), entrapment-FDP-valid |

## Constraints

- Clean-room / Apache-compatible; no patented generating-function; native Rust, single binary.
- Every phase gated by an experiment on real data with provenance (binary commit, list size, truth cutoff). One variable per A/B. Flat/byte-identical = red flag.
- FDR is the highest-blast-radius component → entrapment-FDP-validated, leakage-safe CV.
- All glyco code isolated in `crates/andes-glyco/`; shipped-engine crates touched only at the integration seam.
